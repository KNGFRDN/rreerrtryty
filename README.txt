Governor Digital PR — Static HTML/CSS/JavaScript version

Files:
- index.html        Main entry point
- style.css         Complete styling and responsive layout
- app.js            Navigation, rendering, filters, modals, forms and interactions
- data.js           Website content/data converted from the original React/TypeScript data
- assets/images/    Local image assets used by the site

How to run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. For best results, serve the folder with a simple local server (for example VS Code Live Server).

No React, Vite, Tailwind, TypeScript, Node.js or PHP is required.
